# Ideology / layers

Ideology / layers is a small, client-only political self-reflection experiment. It separates three kinds of statements that are often blended together:

- descriptive: what a person thinks is happening;
- normative: what a person thinks deserves value; and
- prescriptive: what institutions should do.

The current provisional bank contains 1,176 original prompts, 392 per layer, a versioned local dataset, approximate editorial anchors, transparent facet aggregation, coverage warnings, and a share fragment that stores only versioned answers in the URL. The taxonomy exposes an audited canonical inventory of 9 macro families, 33 meso traditions, and 60 micro branches, plus a separate registry for contextual, historical, and associated entries. It uses one canonical macro → meso → micro breadcrumb where that parentage is useful and typed hybrid/overlap/host relations where it is not. Ninety-two source-backed canonical branches have dedicated branch-sensitive coverage and provisional scored anchors, while five broad contextual bridge anchors remain visible for research but are excluded from production neighbor scoring. The v59 through v70 continuations add direct branch-sensitive coverage for Qutbism, Radical Republicanism, Marxist Feminism, Socialist Feminism, Left-Wing Populism, Neoconservatism, Paleoconservatism, Wasatiyya, Right-Wing Populism, Hindutva (Hindu Nationalism), Religious Zionism, and Neo-Fascism on their existing canonical paths. Neo-Fascism is bounded as a historically situated post-1945 field of fascist continuities, adaptations, and revivals, with explicit temporal, organizational, democracy, corporatist, membership, and false-positive boundaries; the new source pass does not treat every radical-right, nationalist, anti-communist, authoritarian, post-fascist, or contemporary formation as Neo-Fascist. These branches do not infer from Muslim or Hindu identity, Jewish identity, private piety or faith, cultural identity, patriotism, moderation as a scalar score, anti-elite dissatisfaction, national pride, immigration concern, anti-minority sentiment alone, one party, one leader, one issue, Israeli citizenship, current territorial or government policy, one symbol, nostalgia, or one historical case. Fascism and the remaining high-risk or under-specified branches remain catalog-only and do not become scored results. It is not a scientific instrument, a diagnosis, a political recommendation, or a claim that any label captures a person.

## Method boundary

Answers are kept in React state. There is no account, API, database, analytics endpoint, or remote answer store. “No view yet” is distinct from “Mixed / depends”; a layer produces a result only when at least half of its prompts have a directional or mixed response.

The scorer compares observed facet values with approximate editorial profiles using signed, effect-weighted facet aggregation and a weighted mean squared distance. It carries a separation margin between neighboring anchors and suppresses percentage-like display when the observed item set does not distinguish close candidates. When all three layers are covered, it also exposes a combined pattern made from one equally weighted layer fit per claim type, with the three contributions visible for inspection. The combined pattern is not an identity assignment, recommendation, or scientific classification. It uses deterministic content and a versioned policy so that a shared result can be rejected safely when the dataset changes. The UI calls these outputs “interpretive neighbors” and “internal fit” rather than treating them as scientifically validated classifications.

## Research workbench

The `Research` view is a quarantined item-authoring surface. It derives its target list from the audited ontology nodes and the separate registry at runtime; it does not maintain a second hardcoded ideology list. Each target is labeled with its measurement state, canonical path where one exists, typed relations, source records, linked-context question IDs, existing constructs, and neighboring branches. “Linked context” is provenance overlap, not evidence that the target is measured.

The current derivation exposes 119 research targets from the 107 ontology nodes and 12 registry entries. It keeps catalog-only, registry-only, contextual-only, scored-indirect, partial-dedicated, and dedicated-scored states distinct. The curated branch pool contains 1,428 effect-free research candidates across all 119 targets, covering the nine macro families, all 33 canonical meso traditions, the source-backed continuation tranches, a bounded contextual/registry pass, and completion coverage for every target; it is displayed in the workbench but is not a respondent-facing bank. The production bank now contains 1,176 prompts, 392 per layer, with 92 provisional dedicated-scored target blocks. Before any candidate can enter the production bank, it must pass a substantive neighbor-distinctness review, a cross-cultural/jurisdictional review where relevant (or a documented not-applicable decision), and later empirical validation.
