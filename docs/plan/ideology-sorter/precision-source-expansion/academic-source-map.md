## Anchor context

Anchors are not treated as scholarly definitions. They are approximate editorial profiles with a context reference chosen to make the underlying family resemblance auditable:

- liberal anchors: Hayek, Rawls, and Nozick;
- socialist and social-democratic anchors: Esping-Andersen, Sen, Rawls, and Ostrom;
- conservative anchors: Jost and Anderson;
- green anchors: Rockström, Gardiner, and Ostrom; and
- libertarian or self-governing anchors: Nozick, Sen, and Ostrom. The new Right-Libertarianism anchor uses SEP Libertarianism and Nozick as conceptual context while retaining a provisional editorial status.

## Combined-pattern boundary

The application now exposes a combined pattern only after descriptive, normative, and prescriptive layers are each covered. It computes one proximity signal per layer and averages those three signals equally, preventing item volume or answer density in a single layer from deciding the composition. This is a local, inspectable display rule informed by Freeden's compositional morphology and multidimensional measurement literature; it is not a validated ideology scale or an identity classifier. The individual layer profiles, neighbors, signals, and cross-layer pulls remain the primary inspection surfaces.

## Validation boundary

The dataset validator fails closed if a question or anchor has no ideology-research source reference. This is a provenance-completeness check, not a validity test. A candidate still requires substantive neighbor-distinctness review, applicable cross-cultural/jurisdictional review, and later empirical validation before production promotion; none of those checks is represented as completed by the current application.
