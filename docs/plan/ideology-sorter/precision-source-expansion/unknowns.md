# Unknowns and Inferred Decisions

## Known knowns

- The preceding baseline bank had 84 original prompts, 28 per layer, and approximate editorial anchors.
- The active continuation has 204 original prompts, 68 per layer, and eleven provisional dedicated-scored target blocks.
- The user observed several labels at 99% and considers the result too coarse.
- Academic source support is required for the construct and item-development rationale.
- The project must not present the output as a scientific diagnosis or political recommendation.

## Inferred decisions

| Decision | Conservative default | Reversal path |
|---|---|---|
| Item-bank size | 204 total, 68 per layer | Add a further versioned batch without changing the scoring API. |
| Source posture | Original local wording with academic/conceptual provenance | Retire or revise an item after documented wording and construct review. |
| Anchor posture | Keep anchors editorial and add source-role metadata | Replace with a separately reviewed calibration dataset later. |
| Result language | Rank neighbors but show low separation explicitly; avoid false percentage precision | Add a validated uncertainty model only after data collection. |
| Share compatibility | Bump content and policy versions so old links fail closed | Add an explicit migration adapter only if an old-link policy is approved. |
| Promotion review | Preserve a documented decision before production language | Require neighbor-distinctness review, applicable cross-cultural/jurisdictional review or a not-applicable rationale, and later empirical validation before promotion; keep wording, target rationale, source rationale, and unresolved risks attached to each revision. |

## Risks to keep visible

- More items can increase burden without increasing construct validity; the 204-item bank remains provisional, and no cognitive review was run in the current continuation.
- Academic citations can support a construct without supporting the local item wording or anchor vector.
- Party-position datasets are context- and time-dependent and must not silently become respondent labels.
- Close neighbors may be a genuine property of a respondent's answers; the UI should communicate ambiguity rather than force a winner.
