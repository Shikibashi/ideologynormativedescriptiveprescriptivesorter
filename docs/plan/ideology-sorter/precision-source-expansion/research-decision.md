# Research Decision — Precision and Source Expansion

## Scope

This is an improvement to the existing 48-item client-only sorter. The request is not to build a party or candidate recommendation system; it is to make the interpretive question bank and the result separation less coarse.

## Selected research

| Area | Decision | Use in this change |
|---|---|---|
| Political-space dimensionality | SELECT | Use multidimensional political-science research to justify separate economic, cultural/order, democratic, ecological, and international signals. |
| Individual ideology and values | SELECT | Use peer-reviewed theory as conceptual background, never as a direct classifier for respondents. |
| Survey-item construction | SELECT | Apply AAPOR and Pew guidance on one concept per item, neutral wording, explicit scope, and documented wording review. |
| Comparative party-position data | SELECT, bounded | Use CHES and Manifesto Project as documented external reference systems, not as respondent labels or current-party recommendations. |
| Substantive promotion review | SELECT | Require neighbor-distinctness review, applicable cross-cultural/jurisdictional review or an explicit not-applicable rationale, and later empirical validation before production canonicalization. |
| Live party/candidate matching | DEFER | It would change the product's scope, freshness contract, and political-advice risk. |
| Machine-learning classification | DEFER | The current deterministic calculation remains inspectable and versioned. |

## Evidence boundary

Academic sources support the choice of constructs, multidimensional framing, and item-development process. They do not validate this project's hand-authored anchor vectors or establish that a respondent belongs to an ideology. Each local item and anchor remains an editorial record with explicit provenance and versioning.
