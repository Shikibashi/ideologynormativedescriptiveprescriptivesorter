# Domain Review — Precision and Academic Source Expansion

## Findings

1. Multidimensionality is the relevant academic safeguard: a single ideological label or axis can hide cross-cutting preferences. The UI should display layer-specific neighbors and an ambiguity state rather than infer one identity.
2. The current hand-authored anchors are editorial profiles. Academic sources can justify construct separation and measurement discipline, but they do not calibrate the vectors automatically.
3. Social democracy, social conservatism, liberalism, and related traditions can overlap on some dimensions while diverging on others. The item bank should therefore add targeted items for material distribution, public provision/ownership, cultural pluralism/order, institutional constraint, and international scope.
4. A larger item bank requires more—not less—item-level review. AAPOR and Pew guidance support clear claims, iterative wording review, and transparent reporting; the project should record these as editorial controls rather than scientific validation.

## Dictionary updates

- **Construct source:** A cited academic or methodological work that supports a dimension, wording principle, or documented editorial-review criterion; it is not an anchor truth claim.
- **Separation:** The ordered difference between a neighbor's proximity and the next candidate's proximity; low separation means the item set does not distinguish them strongly.
- **Provisional bank:** An item set that is runnable and versioned but remains an editorial prototype rather than a scientifically validated instrument.
