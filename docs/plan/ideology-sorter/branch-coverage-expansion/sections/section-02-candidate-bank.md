# Section 2: candidate bank

The candidate bank uses existing facets and response format. Each item is tagged with a layer, target justification, theory context, item function, expected qualitative direction, neighbor alternatives, rationale, risks, and source IDs. The bank is intentionally overinclusive at the research stage. It is not a list of claims that respondents must accept, and it is not a list of production weights.

Every block includes descriptive mechanisms, normative commitments, and prescriptive routes. The same-answer/different-reason risk is recorded per item and is paired with a target-level neighbor matrix. False-positive audits identify common reasons a respondent might agree with an item without holding the target tradition.
