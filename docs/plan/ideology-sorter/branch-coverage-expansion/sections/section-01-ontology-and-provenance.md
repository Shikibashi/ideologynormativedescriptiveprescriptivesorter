# Section 1: ontology and provenance

The canonical graph keeps one explicit ancestry path where useful, while typed relations carry cross-family, historical, hybrid, and host relationships. Khomeinism and Qutbism are the only new canonical nodes in this continuation. Both are micro-level, parented to Islamism for stable scope, source-backed, catalog-only, and unanchored. Their parentage does not imply that Islamism is a religious macro root; Islamism remains a parentless meso node.

The local source registry records scholarly pages rather than using a search result or a generic encyclopedia as the support boundary. Each source says what it supports and what it does not establish. A source-backed summary is not an authority grant and cannot activate scoring.
