# Section 4: verification and boundaries

Verification is layered: TypeScript and unit tests for contracts, Playwright for the existing user paths plus the research shelf, and Docker for the static delivery image when available. Argos checks that production scoring remains unchanged, source and relation references close, and the quarantine boundary is visible.

The final status can prove structural completion without proving respondent validity. Any missing browser, Docker, or empirical signal stays visible in the Zeus report.
